# Vendored visual fonts (LR-E20 / T-E-58)

Per-family folders with `OFL.txt` (SIL OPEN FONT LICENSE Version 1.1) and latin `.woff2`.
`manifest.json` records SHA-256 of each vendored file. Harness serves these via
`page.route` for fonts.googleapis.com / fonts.gstatic.com.
Production keeps Google Fonts `<link display=swap>`.
