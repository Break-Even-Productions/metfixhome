## 3. Acceptance items
### Worker API
- **A1 Routes.** `worker/index.ts` dispatches exactly `/api/posts` and `/api/posts/{id}` before the `/api/*` catch-all; `/api/posts/` behaves as `/api/posts`. Any other `/api/posts/...` path (e.g. `/api/posts/1/comments`, `/api/posts/abc`) → existing JSON 404. Other methods → 405 `Allow: GET, HEAD`. HEAD returns the GET status and headers with no body.
- **A2 List params (W4, W6).** Only `page` is read. Absent → 1. `page` must match `^[1-9][0-9]*$` and be ≤ 50; anything else (`0`, `-1`, `1.5`, `abc`, `51`, `999`, empty, repeated `page`) → **400 `{"error":"bad_page"}`**, `Cache-Control: no-store`, no upstream call, nothing stored in the Cache API. Every other query param is ignored and never forwarded. The upstream URL is built only from constants plus computed `limit=PAGE_SIZE`, `offset`, `preview=true`.
- **A3 Detail id (D4).** `{id}` must match `^[1-9][0-9]{0,9}$` and be ≤ 2147483647 (regex and max exported from `shared/posts/`, CQ13); else the **catch-all JSON 404 byte-for-byte** (no Cache-Control) without an upstream call (CQ2).
- **A4 Upstream request.** Built in `worker/upstream.ts` (or `worker/posts.ts` reusing its helpers); passes `assertBsiHost`; headers are **exactly** `Accept: application/json`, `X-API-Key: env.BSI_POSTS_API_KEY`, `User-Agent: metfixhome-worker/1.0` (`UPSTREAM_USER_AGENT`). No `Authorization`/Bearer (C§10(a)), Cookie, X-WP-Nonce, X-Forwarded-For, X-Real-IP, CF-Connecting-IP, True-Client-IP, Forwarded, Referer, Origin; incoming request headers are never copied. `method: "GET"`, `redirect: "manual"` (3xx = upstream error), `AbortSignal.timeout(3000)`.
- **A5 No key → 503.** Missing/empty `BSI_POSTS_API_KEY` → `nokey` → 503; never a call without the key, never a fallback to `DAILY_FIX_API_KEY`.
- **A6 List mapping (C§3).** 200 body `{ posts: Post[], page, per_page: PAGE_SIZE, has_more }`; `has_more` per §0d G6 (1.1.5): `page*PAGE_SIZE < meta.total` (non-negative integer) AND `page < 50`; `meta.has_more` ignored; invalid `meta.total` → 503. Post = `{ id:int>0, title:string (≤200 after trim, else drop), excerpt:string (plain text, tags stripped, ≤500), date:ISO string (unparseable → drop), image: https URL|null (A10), author: string|null, category: {name, slug}|null }`. Drop non-object items and D8 failures. `posts` not an array or `meta` not an object → unmappable → 503. Upstream `posts: []` → 200 empty list (offset beyond total is 200, C§4). **Note (1.1.6 N4, accepted; 1.1.7 N4a):** `meta.total` counts posts before the Worker's D8/mapper drops, so it can over-count; on an empty last page `has_more` can be **true or false**, and such a page renders empty ("No posts on this page." with its links, G1). Accepted; not a defect.
- **A6a Permalink (W3, E1).** Detail only (preview items have none, C§3). Forwarded as `permalink` iff `new URL()` parses, protocol `https:`, hostname exactly `brokenscience.org` (no `www.`, no subdomain, no port, no userinfo); else `null`. Used for the canonical (A18) and a "Read on Broken Science" link (A20).
- **A7 Detail mapping.** 200 body `{ post: Post & { content: sanitizedHtml, permalink: string|null } }`. Upstream `post` missing/unmappable → 503. D8 failure → 404 (A9). `content` empty after sanitization → still 200 (client shows excerpt).
- **A8 Status mapping (C§4, C§10.C1).** upstream 404 `post_not_found` (or `rest_no_route`) → 404 `{"error":"not_found"}`, `Cache-Control: public, max-age=60`. 400, 401, 403, 429, other 4xx, 5xx, 3xx, timeout, throw, bad JSON → 503 `{"error":"unavailable"}`, `Retry-After: 300`, `Cache-Control: no-store`. Upstream error code/message/text never echoed. `X-RateLimit-*` upstream headers are ignored (C§3).
- **A9 Locked filter (D8, OQ-P2).** Locked = `is_exclusive !== false` or non-empty `access_levels` (plus D8's other fail-closed checks); an expired exclusive reported unlocked is served. Applied in the Worker to every list item and the detail post **before** caching. A filtered detail → 404 identical in body, headers and status to an upstream 404. The cache never holds locked bytes.
- **A10 Images (C§6, C§9.6; 1.1.2 DR6).** `featured_image` accepted only if `new URL()` parses, `https:`, no credentials, no port, hostname exactly `brokenscience.org` (§0b DR6); else `null`. Same rule for every `img src`/`srcset` URL in `content`; relative image URLs are resolved against `https://brokenscience.org/` and then checked.
- **A11 Caching (W2).** Cache API with synthetic keys `https://metfix.org/__cache/posts/list?page=N` and `.../__cache/posts/{id}` (helper beside `cacheTtl.ts`; never the raw request URL). Stores the mapped, filtered JSON only. TTL list `s-maxage=300`, detail `s-maxage=600`. 400, 404 and 503 are never stored. Client headers = `apiOkHeaders()` (browser `max-age=60`). Corrupt entry → refetch.
- **A12 Quota (W2, C§9.2, C§10(c)).** No rate-limit binding; cache (A11) is the only guard. The PR body states: BSI allows 60/60 s per key per path today, and after BSI's scoping PR all detail ids share one 60/60 s bucket, so a cold-cache burst can produce 503s (§6.2 Q-BSI-3).

### Sanitization

Comments removed. Upstream body > 1,048,576 bytes → 503 (Q9). Attribute, link and image rules per §0b Q8, Q10–Q12, G2.
