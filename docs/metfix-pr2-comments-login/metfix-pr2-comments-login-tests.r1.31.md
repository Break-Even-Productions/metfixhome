## 0. Rules (apply to every item)
- **R-exact.** Assert exact status, exact body bytes (or exact parsed JSON with `toStrictEqual`, so extra keys fail), exact header values. `toBeTruthy`, `toBeDefined`, `toContain` on a status, snapshot-only and "renders without crashing" are **not** passes.
- **R-nowrite.** Every denial asserts the **no-write set** `NW`: 0 calls to any BSI URL, 0 siteverify calls (unless the item says the check runs before it), 0 `AUTH_SESSIONS.put`/`delete`, 0 `cache.put`/`cache.delete`, 0 rate-limit consumption where the item says the check runs before the limiter, and no `Set-Cookie: __Host-mfx_sid` in the response.
- **R-realauth.** No mocked auth. Sessions are created only by driving the real routes (`GET /api/auth/csrf` → `POST /api/auth/login` or the Google callback) through `handleRequest` with the PR's real session, CSRF, AES-GCM and cookie code. Only the network edges are faked: BSI, Google token/JWKS, reCAPTCHA siteverify (via `fetchImpl`), KV (in-memory fake that records `put` options incl. `expirationTtl`), Cache API (recording fake), the Rate Limiting binding (recording fake, atomic counter), and the clock (`vi.setSystemTime`).
